Project Description:

In this project, you will choose one real-world dataset and investigate a meaningful research question using Python and data analysis techniques learned throughout the semester. The goal is to simulate how data analysts work in industry: from raw data to insights and prediction.

Dataset Theme:

Traffic Accidents

Analyze accident conditions and severity.
Examples of research questions:

What weather or road conditions lead to more severe accidents?
Are accidents more frequent at certain times of day?
Can we predict accident severity based on environmental factors?

You must clearly define ONE research question for your project.

Research Question Requirement

Your project must include a written research question in this format:

“In this project, we aim to investigate whether **\_\_** influences **\_\_** using real-world data.”

Examples:

“In this project, we investigate whether discount percentage influences profit in retail sales.”
“In this project, we investigate whether patient age and diagnosis predict hospital readmission.”
“In this project, we investigate whether house size and location predict housing prices.”
Each project must begin with a clearly written research question stated on the first page of the report. The research question should follow the required format and guide the entire analysis. Projects that do not include a clear research question will be penalized.

Required Tasks:

1. Data Loading:
   Load your dataset using Python (CSV or JSON).

2. Data Cleaning:
   Handle missing values by removing rows or filling values with mean, median, or mode. Explain your choice.

3. Descriptive Statistics:
   Compute and explain:

- Mean
- Median
- Variance
- Standard deviation
- Group statistics

4. Data Visualization:
   Create at least:

- Bar plot
- Histogram
- Scatter plot
  All plots must include titles and axis labels.

5. Linear Regression:
   Use regression to answer a predictive question and explain:

- Inputs (X)
- Output (y)
- Interpretation of results

6. Machine Learning Model:
   Use one ML model:

- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors
  Explain what you predict, model accuracy, and features used.

7. Optional (Bonus) NLP:
   If dataset includes text, perform:

- Text cleaning
- Sentiment analysis
- Word frequency
- Tokenization

Deliverables:

1. Source code:

- Clean and well-commented
- Organized sections: Data Loading, Cleaning, Analysis, Visualization, Regression, ML

2. Short Report (2–4 pages):

- Problem statement
- Dataset description
- Key findings
- Model results
- Conclusion

3. Presentation (8–10 minutes):

- Visual results
- Explanation of methods
- Final insights
